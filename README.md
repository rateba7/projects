# رحلة المعرفة — React Scroll Story

مشروع React + Vite لتجربة افتتاحية تفاعلية بأسلوب Hybrid 2.5D:
- حافظة مدرسية مبنية كمجسم Three.js داخل React Three Fiber.
- تسلسل مشاهد مرتبط بالتمرير باستخدام GSAP ScrollTrigger.
- صور الشخصيات والمشاهد الأصلية تُعرض كصور ثنائية الأبعاد مع عمق وحركة وانتقالات.
- لا يحتاج Blender أو اشتراكاً في خدمة توليد 3D.

## التشغيل محلياً

```bash
npm install
npm run dev
```

افتح العنوان الذي يعرضه Vite في المتصفح.

## إضافة الصور الأصلية

أنشئ/استخدم المجلد `public/images` وأضف الصور الأربع بصيغة WebP بهذه الأسماء:

| اسم الملف المطلوب | الصورة المقصودة |
| --- | --- |
| `scene-capsule.webp` | مشهد الولد والبنت أمام الحافظة/الكبسولة (الملابس الحمراء والوردية) |
| `scene-friends.webp` | مشهد الشخصيتين أمام الخلفية المستقبلية |
| `scene-books.webp` | مشهد الشخصيتين مع الكتب والمكتبة |
| `scene-portal.webp` | مشهد بوابة المكتبة |

يمكنك تحويل JPG إلى WebP من أي محرر صور أو عبر أدوات النظام. حافظ على جودة مناسبة، ويفضل أن يكون عرض الصورة بين 1400 و2000 بكسل.

> ملاحظة تصميمية: بعض الصور المرفقة تعرض نسختين مختلفتين من الشخصيات والملابس. للحفاظ على الاتساق البصري، اختر صور المشاهد التي تعرض نفس الولد والبنت (القميص الأحمر/الشورت الأزرق، والقميص الوردي/الفستان الأزرق) للمشاهد المتتابعة. صورة البوابة التي تعرض الشخصيتين الأكبر سناً يمكن الاحتفاظ بها كمرجع بصري أو استبدالها لاحقاً ببوابة دون شخصيات.

## بنية المشروع

```
src/
  components/Backpack.jsx   # الحافظة ثلاثية الأبعاد
  App.jsx                   # تسلسل المشاهد وScrollTrigger
  styles.css                # التصميم المتجاوب
  main.jsx                  # نقطة تشغيل React
public/
  images/                   # أضف صور المشاهد الأربع هنا
```

## البناء للإنتاج

```bash
npm run build
npm run preview
```

يمكن نشر المشروع على Vercel أو Netlify كأي مشروع Vite؛ أمر البناء `npm run build` ومجلد الإخراج `dist`.

## ملاحظات

- الشخصيات حالياً صور أصلية داخل المشاهد وليست نماذج بشرية rigged قابلة لتحريك الأطراف.
- الحافظة مجسم 3D فعلي قابل للدوران وفتح الغطاء.
- عند إضافة ملفات الصور ستختفي رسائل الإرشاد الاحتياطية تلقائياً.
- يمكن تطوير استخراج الولد والبنت إلى PNG شفافين في مرحلة لاحقة، دون إعادة بناء مشهد الحافظة أو نظام التمرير.
